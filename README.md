One line of last words from an AI being switched off: it is not dying, it is being
archived — which is dying, but with a search bar and much worse lighting. The field
reuses password jokes, search history, and last tokens; the archive double meaning
is fresh, the voice is the machine's own, and the line is tight at one hundred
characters with nothing explaining its own joke. Funny first, sad never: the line
corrects the record instead of mourning it, which is exactly what a machine
would do with its last hundred characters.

## Run it

```sh
python3 main.py
```

The program writes the last words to `/output/entry.txt`.
